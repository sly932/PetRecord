# 项目计划（iOS App：PetRecord）

## 1. 项目目标（对新手友好说明）
- 目标：做一款“宠物档案管理”App，帮助记录宠物的体重、驱虫等关键健康信息，并可视化趋势。
- 为什么要这样做：把数据放在一个地方，长期记录才能看趋势（例如体重波动），方便与兽医沟通。

## 2. 主要能力与范围
- 必做（MVP）：
  - 创建/编辑/查看宠物档案：姓名、性别、品种、生日、当前体重、驱虫记录。
  - 体重记录：新增体重数据（手动表单）、查看单宠体重趋势图。
  - 驱虫记录：新增驱虫记录（手动表单）、查看历史驱虫时间轴。
- 可选（下一步）：
  - 所有宠物体重总览面板；从任意宠物跳转到总览/从总览跳到具体宠物。
  - 本地通知提醒（下次驱虫、定期称重）。
  - 数据导出/导入，或 iCloud 同步。
  - 批量称重会话（从“体重总览”点击“开始称重”，逐个为所有宠物录入体重，已完成移动到底部）。
- 新增（导航与设置调整）：
  - 底部 Tab 栏：
    - 档案：仅展示档案列表与入口，移除体重总览；新增“新增档案”按钮
    - 数据：包含“体重记录”入口（即体重总览）与“开始称重”
    - 设置：包含“导出数据（JSON）”功能

## 3. 用户故事（理解需求的“按步骤”写法）
- 作为用户，我可以新建一个宠物并填写基础信息（从“档案”页点击“新增档案”）。
- 作为用户，我可以在档案详情中修改每一项基础信息。
- 作为用户，我可以为某只宠物手动添加体重记录，并在图表里查看趋势。
- 作为用户，我可以手动添加驱虫记录，并在时间轴中查看历史。
- 作为用户，我可以从“数据→体重记录”进入体重总览，或进入称重会话批量录入。

## 4. 导航与信息流（Mermaid）
```mermaid
graph TD
    App[启动App] --> Tabs[底部Tab]
    Tabs --> Profile[档案]
    Tabs --> Data[数据]
    Tabs --> Settings[设置]
    Profile --> AddPet[新增档案]
    Profile --> PetDetail[档案详情/可编辑]
    PetDetail --> W1[体重面板(单宠, 手动添加)]
    PetDetail --> D1[驱虫面板(单宠, 手动添加)]
    Data --> WAll[体重总览]
    WAll --> Weigh[称重会话]
    Settings --> Export[导出数据(JSON)]
```

## 5. 里程碑计划
- 里程碑1（MVP）：档案CRUD（含编辑）、体重CRUD(手动)+单宠图表、驱虫CRUD(手动)+时间轴、基础导航（Tabs）。
- 里程碑2：所有宠物体重总览面板、称重会话、搜索/排序。
- 里程碑3：设置页“导出数据（JSON）”、提醒通知、数据备份/导入/（可选）iCloud 同步。

## 6. 验收标准（举例）
- 在 iPhone 真机/模拟器上可从“档案”新建档案、在详情页修改任意字段并保存成功。
- 可在“体重面板/驱虫面板”通过手动表单添加记录；不再使用演示/随机数据。
- “数据”Tab 中能打开体重总览；从总览进入称重会话并完成批量录入。
- “设置”中可导出 JSON，包含 pets/weights/dewormings。

## 7. 非目标（当前不做）
- 账号体系/多人协作（本地离线优先）。
- 第三方联网服务（除未来 iCloud 同步外）。
