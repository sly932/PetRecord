# 项目计划（iOS App：PetRecord）

## 1. 项目目标（对新手友好说明）
- 目标：做一款“宠物档案管理”App，帮助记录宠物的体重、驱虫等关键健康信息，并可视化趋势。
- 为什么要这样做：把数据放在一个地方，长期记录才能看趋势（例如体重波动），方便与兽医沟通。

## 2. 主要能力与范围
- 必做（MVP）：
  - 创建/编辑/查看宠物档案：姓名、性别、品种、生日、当前体重、驱虫记录。
  - 体重记录：新增体重数据、查看单宠物体重趋势图。
  - 驱虫记录：新增驱虫记录、查看历史驱虫时间轴。
- 可选（下一步）：
  - 所有宠物体重总览面板；从任意宠物跳转到总览/从总览跳到具体宠物。
  - 本地通知提醒（下次驱虫、定期称重）。
  - 数据导出/导入，或 iCloud 同步。

## 3. 用户故事（理解需求的“按步骤”写法）
- 作为用户，我可以新建一个宠物并填写基础信息。
- 作为用户，我可以为某只宠物添加体重记录，并在图表里查看趋势。
- 作为用户，我可以记录驱虫时间与药物，并在时间轴中查看历史。
- 作为用户，我可以从某只宠物进入体重面板，也可以从“所有宠物体重面板”进入某只宠物。

## 4. 导航与信息流（Mermaid）
```mermaid
graph TD
    A[启动App] --> B[宠物列表/主页]
    B -->|点某只宠物| C[宠物档案详情]
    C --> C1[体重面板(单宠)]
    C --> C2[驱虫记录面板(单宠)]
    B --> D[所有宠物体重面板]
    C1 -->|查看更多宠物| D
    D -->|点某宠物曲线| C1
```

## 5. 里程碑计划
- 里程碑1（MVP）：档案CRUD、体重CRUD+单宠图表、驱虫CRUD+时间轴、基础导航（首页→详情→面板）。
- 里程碑2：所有宠物体重总览面板、面板互相跳转优化、搜索/排序。
- 里程碑3：提醒通知、数据备份/导出、（可选）iCloud 同步。

## 6. 验收标准（举例）
- 在 iPhone 真机/模拟器上可新增宠物、体重、驱虫，并能持久化保存后再次打开看到相同数据。
- 单宠体重图表正确渲染，新增数据后能看到趋势变化。
- 从单宠体重面板能跳到“所有宠物体重面板”，再能返回。

## 7. 非目标（当前不做）
- 账号体系/多人协作（本地离线优先）。
- 第三方联网服务（除未来 iCloud 同步外）。
