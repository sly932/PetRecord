# UX 设计与导航决策

## 1. 主要界面
- 档案（Tab）：展示所有宠物档案卡片；顶部或右上角提供“新增档案”按钮；不再包含体重总览入口
- 宠物档案详情：展示姓名、性别、品种、生日、当前体重摘要、驱虫概览；支持编辑
- 体重面板（单宠）：体重记录列表 + 趋势图（Swift Charts）+ 手动新增记录（表单）
- 驱虫面板（单宠）：驱虫记录时间轴 + 手动新增记录（表单）
- 数据（Tab）：体重总览入口；含“开始称重”进入称重会话
- 称重会话（批量称重）：逐个录入所有宠物体重，已完成下沉到底部
- 设置（Tab）：导出数据（JSON）

## 3. 档案详情编辑交互（方案对比）
- 方案A：页面右上角“编辑”按钮，进入编辑模式
  - 优点：
    - 清晰的模式切换（查看 vs 编辑），避免误触
    - 可一次性编辑多个字段，统一“保存/取消”
  - 缺点：
    - 需要额外进入/退出步骤
- 方案B：每个字段右侧提供“铅笔”图标或“修改”按钮，点按行内编辑
  - 优点：
    - 就地编辑，颗粒度细
  - 缺点：
    - 列表视觉噪音较大；多字段编辑需要多次保存
- 推荐方案：
  - 采用方案A为主（右上角“编辑”切换编辑模式）；在关键字段（如头像/照片）可保留就地操作入口
  - 编辑模式下，字段以表单控件呈现，底部提供“保存/取消”

## 4. 体重/驱虫“手动添加”表单
- 体重：日期（默认今日）、体重kg（必填，>0）、备注（可选）
- 驱虫：日期（默认今日）、药品（必填）、剂量/备注（可选）
- 校验失败：在字段下方显示错误消息；不阻塞其他界面

## 5. 交互与可用性要点
- 可访问性：动态字体、对比度、VoiceOver 标签
- 表单校验：体重>0、日期默认今天；错误提示明确
- 删除与撤销：敏感操作提供确认或“撤销”提示
- 空状态：无数据时展示指引与“添加”入口
- 批量称重：保存成功后该宠物“下沉”到底部分组
